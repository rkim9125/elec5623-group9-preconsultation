# 병력 태그 입력

비로그인 `/#history`와 계정 문진 작성·이어쓰기는 동일한 `HistoryInput`을 사용한다. 복용약 `/#medicines`도 공통 `TagChoices`의 디자인·체크박스·키보드 동작을 재사용한다. 적용 범위는 병력과 복용약이며 알레르기 등 다른 입력은 유지한다. `src/history.js`의 `historyOptions`에서 병력 ID와 번역 키를 관리하며, 목록은 데모 예시이지 완전한 병력 목록이나 임상적으로 검증된 분류가 아니다.

## 데이터 호환

문진 `version: 1`에 선택적 필드 `history.tags`를 추가한다.

```json
{
  "history": {
    "status": "answered",
    "tags": ["diabetes", "surgery"],
    "value": "사용자가 직접 작성한 추가 설명"
  }
}
```

- 새 답변 기본값은 `{ status: "unasked", value: "", tags: [] }`이다.
- 기존 `{status, value}`는 그대로 읽는다. `tags` 누락은 빈 배열로 취급하며, 최초 병력 편집 시 추가한다. 저장 데이터 일괄 마이그레이션이나 기존 텍스트의 진단명 추론은 하지 않는다.
- ID는 `diabetes`, `hypertension`, `asthma`, `heart-disease`, `kidney-disease`, `liver-disease`, `surgery`다. 표시와 편집 시 중복을 제거한다. 알 수 없는 기존 ID도 삭제하지 않고 요약에서는 원래 ID를 표시한다.
- `none`, `unknown`, `declined`에서는 태그·설명을 비활성 초안으로 보관한다. 체크박스는 선택되지 않은 비활성 상태, 설명은 읽을 수 있는 비활성 입력으로 표시한다. 안내와 ‘다시 편집’ 버튼으로 복원할 수 있으며, 환자 요약과 의사 요약·원문에는 선택한 응답 상태만 표시한다.
- 모든 태그와 설명을 지우면 `unanswered`로 기록한다. 명시적 `none`으로 바꾸지 않는다. 병력 변경은 기존 `change()`를 통해 검토 승인을 해제한다.
- 동일 탭의 기존 sessionStorage 정책을 사용한다. 언어 전환은 표시만 바꾸며 저장·답변 변경을 발생시키지 않는다. 자유 입력은 원문을 유지한다.

## 요약과 제출

환자 요약·텍스트 다운로드는 태그 ID를 현재 언어로 표시하고 추가 설명을 함께 표시한다. 제출 시 기존 구조화 스냅샷 복사에 `tags`와 `value`가 포함된다. 기존 전달본은 재작성하지 않는다. Doctor Dashboard의 병력 요약과 환자 원문도 같은 표시 함수를 사용한다. 응답 상태가 `answered`가 아니면 보관된 비활성 값은 표시하지 않는다.

## 검증

`npm test`의 `history.test.js`는 기존 텍스트 호환, 중복 제거, 상태 배타성, 재검토, 저장 복원, 제출본 불변성과 의사 서비스 전달을 확인한다. `tests/browser/history.spec.js`는 태그·텍스트 조합, 키보드, 언어 전환 시 저장 없음, 뒤로가기·새로고침·계정 이어쓰기, 의사 요약·원문, 360px/1440px 레이아웃과 자동 접근성을 확인한다.

실제 의료 분류 검증이나 서버 API 변경은 포함하지 않는다. 브라우저 mock과 기존 저장 범위를 유지한다.

## 복용약 태그

`src/medicines.js`가 예시 약 종류 ID와 표시 규칙을 관리한다. `medicines.tags`에 `diabetes-medication`, `blood-pressure-medication`, `cold-medication`, `pain-relief`, `stomach-medication`, `allergy-medication`, `sleep-medication`, `other`를 저장한다. 기존 `items: [{name, detail}]`와 분리하며 `detail`에는 용량·복용 빈도 등 사용자가 입력한 원문을 보존한다. 약 이름·성분·용량을 추정하거나 태그에서 상세 항목을 생성하지 않는다.

- 새 기본값은 `{status: "unasked", value: "", items: [], tags: []}`다. 버전 1을 유지하고 기존 태그 없는 데이터는 빈 배열로 읽는다. 기존 항목은 변환·삭제하지 않는다.
- 태그만으로 진행할 수 있다. 사용자가 명시적으로 상세 입력을 선택하거나 항목 추가를 눌렀을 때만 입력 행을 만든다. 빈 약 이름·용량도 기존처럼 허용한다. 태그 해제는 별도 상세 항목을 삭제하지 않는다.
- `none`, `unknown`, `declined`는 태그와 상세를 비활성 초안으로 보관하며, 안내 및 ‘다시 편집’ 버튼을 제공한다. 요약·의사 원문에는 활성 응답 상태만 표시한다. 마지막 태그·항목을 제거하면 `unanswered`로 기록하며 `none`을 추론하지 않는다.
- 요약은 ‘선택한 약 종류’와 ‘입력한 약 상세’를 구분한다. 둘의 대응 관계를 추론하지 않는다. 태그만 있거나 상세 행이 모두 비었으면 정확한 약 이름·용량 미확인을 표시하며, 의사 화면의 미확인 정보에도 연결한다.
- 기존 스냅샷 복사에 태그와 상세가 함께 포함된다. 의사 요약·원문은 동일한 표시 함수를 사용하고 이전 전달본을 재저장하지 않는다. 언어 전환은 태그·제목만 번역하고 자유 입력·저장된 스냅샷은 유지한다.

추가 검증은 `tests/medicines.test.js`와 `tests/browser/medicines.spec.js`에서 다중 선택, 상세 CRUD, 상태 배타성, 복원, 다국어, 재검토, 계정 제출·의사 원문 및 360px/1440px 레이아웃을 다룬다.
